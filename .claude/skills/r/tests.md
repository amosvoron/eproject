For the Deliverable change specifically, consider **#1–#15 and #31–#36 the acceptance suite**. If those all behave correctly, the loophole that caused the original problem is effectively closed.

Pay special attention to **#10, #12, and #13**. Those are the behavioral tests most likely to reveal whether the agent still thinks “interesting information I want to tell the human” is a Deliverable. The correct mental model should be very obvious from the results:

**request work → Body; explicitly requested `-d` sidecar → Deliverable.**
